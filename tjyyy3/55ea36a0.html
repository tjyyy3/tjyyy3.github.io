4.为什么会这样？

个人认为是git pull --rebase <branch>的时候选择了错误的分支（your-branch）或者是重复了两次这个命令且选择的是不同的分支，导致有来自master分支的commit rebase到了当前分支上。

（不是很明白。但再遇到知道该怎么解决了）

5.push到远程仓库后发现还有问题

  1. 撤销最新提交并保留更改： git reset HEAD^。修改更改后，再重新push。
  2. 撤销最新提交并丢弃更改：
    1. git reset --hard HEAD^。慎用，这将永久丢弃刚才所做的更改。
    2. git reset --soft HEAD^。撤销提交但保留更改。
  3. 创建新的修复提交。
